# 동탄점 매출 분석기

바탕화면의 **동탄점 매출 분석기** 아이콘을 누르면 이 컴퓨터에서 열립니다. 개발 환경에서는 `node server.mjs`로 실행하고 [동탄점 매출 분석기](http://127.0.0.1:58123/)를 열면 됩니다. Node.js가 필요합니다.

GitHub에서 내려받은 새 복사본은 빈 매출 화면으로 열립니다. 첫 자료 가져오기에서 로컬 `data/report.json`이 생성됩니다. 기존 PC의 매출을 이어 보려면 `data/report.json`과 작년 11월 기준 자료 `data/prior-month.json`을 새 복사본의 `data` 폴더로 직접 옮겨 주세요. 매출 자료와 API 인증 설정은 GitHub 저장 대상에서 제외합니다.

기간과 채널을 선택하면 총매출, 판매수량, 전년실적과 일자별 추이를 볼 수 있습니다. 날씨는 기상청 수원 관측소의 같은 달과 날짜를 비교합니다. 당일 관측값은 잠정값이며, 원자료에 없는 수치는 공란으로 표시합니다.

11월 누적 그래프의 작년 선은 11월 전체이고, 올해 선은 선택한 기간에 매출 자료가 있는 날짜까지입니다. 날씨 아이콘은 기상청에서 제공한 날씨 현상과 관측값을 기준으로 표시합니다.

**7일 예보와 상품 준비**는 동탄점 예보를 보고 의류 후보를 고른 뒤 네이버 데이터랩에서 각 검색어의 최근 7일과 직전 7일을 비교합니다. 네이버 데이터랩은 등록기에 설정된 기존 API를 조회에 사용합니다. 등록기를 켜지 않아도 분석기가 직접 조회할 수 있습니다.

다른 PC에서 데이터랩을 연결할 때는 `NAVER_CLIENT_ID`와 `NAVER_CLIENT_SECRET`을 실행 환경에 설정하거나, `LOTTE_SALES_NAVER_SETTINGS`로 해당 PC의 로컬 인증 설정 파일 위치를 지정해 주세요.

자료를 갱신하려면 Chrome의 롯데백화점 파트너포털에서 **일자별 매출** 조회를 마친 뒤 **롯데 매출 표 복사** 북마크를 누릅니다. 복사된 자료를 분석기의 가져오기 칸에 붙여넣으면 같은 날짜의 값이 새 조회값으로 바뀝니다. 매출 자료는 이 컴퓨터의 `data/report.json`에 저장됩니다.

매출 전년실적은 포털의 일자별 매출 표에 표시된 값을 사용합니다. 날씨는 같은 날짜를 기준으로 조회합니다.
